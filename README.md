Бот для приёма заявок

Что делает — принимает сообщение в личку и пересылает в группу.

Настройка:
1. Создай бота у @BotFather -> /newbot -> скопируй токен
2. Создай группу, добавь бота админом, узнай ID через @getmyid_bot ГЛАВНОЕ СДЕЛАЙ ЕГО ПУБЛИЧНЫМ И ДОБАВТЕ САМОГО БОТА В ГРУППУ
3. Создай .env рядом с bot.py в него вставте текст ниже
```
BOT_TOKEN=токен
CHAT_ID=id_группы
```
вместо токен и id_группы заменити их на свои
Запуск:
pip install -r requirements.txt
python bot.py
